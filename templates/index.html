⚙ 系统设置

  

    

      不填也能用。 现在全流程由内置引擎跑通；填了下面接口，分析和文案会换成你自己的 AI 服务，出片环节不受影响。
    


    

      使用说明 · 五步怎么用（给老板看）
      
    
        
  1. 找素材：贴同行抖音分享链接点「采集」，或把已下载的视频直接上传。抖音反爬导致采集失败很常见，改用上传一样能跑通全流程。
    2. 
        
  2. 补文案 → 分析：点素材行的「补文案」，粘贴同行口播文字最准（也可传 .srt/.txt）；再点「分析 →」，结构化报告自动进经验库。
    3. 
        
  3. 出文案：填选题 / 地域 / 时长 → 生成 → 可直接改 → 合规检查 → 点「定稿，去拍摄」。经验库越攒越厚，出稿越贴实际。
    4. 
        
  4. 拍口播：复制定稿文案进提词器，手机竖屏念一遍，把原片传上来即可。
    5. 
        
  5. 剪成片：选模板 → 开始自动剪辑 → 右侧直接预览 → 下载发抖音。片头、字幕、水印、片尾、竖屏统一都是模板自动完成的。
    6. 
      

    


    

      运维速查 · 部署 / 配置 / 排错
      
    
        
  • 启动：cd /workspace/douyin-studio && PORT=8080 python3 app.py，浏览器访问 http://服务器IP:8080。内部几个人用，自带多线程模式足够；健康检查 /healthz。
    • 
        
  • 依赖：Python 3.11 + flask / Pillow / yt-dlp；系统要有 ffmpeg、ffprobe 和中文字体 fonts-noto-cjk（字幕与片头卡片靠它，缺了会显示方框）。
    • 
        
  • 配置文件：config/settings.json 接口开关（也可在本页改）、config/edit_templates.json 剪辑模板、config/sensitive_words.txt 一行一个敏感词、config/generate_prompt.txt 业务边界补充规则。改完刷新页面生效。
    • 
        
  • 数据与备份：全部业务数据在 data/studio.db 一个 SQLite 文件里，复制它即备份；素材与成片在 data/uploads/、data/outputs/，建议一起打包。上传上限 1GB。
    • 
        
  • 没有 AI 接口：分析与文案由内置规则引擎跑，全流程可用，顶部显示「内置引擎模式」；填入 OpenAI 兼容接口后才切换成自有 AI，剪辑环节始终不受影响。
    • 
        
  • 批量采集报告：第 2 步输入一段文字即可一键采报告。默认 mock 演示数据源，不联网不花钱；在下面切到 tikhub 并填 Key 后换成真实抖音数据，代码零改动。报告都进同一张 reports 表，第 3 步生成文案直接可用；演示数据会带来源标记，不会冒充真实采集结果。
    • 
        
  • 抖音采集失败：先在下面填浏览器 Cookie；仍失败就直接上传本地视频，后续环节完全相同。
    • 
        
  • 剪辑失败：看第 5 步任务日志，多数是源视频无音轨或编码异常，用 ffmpeg 转成标准 mp4（H.264 + AAC）再传。
    • 
        
  • 安全：默认无访问密码，仅限内网。要放公网必须先开启下面的「访问密码」并挂 HTTPS 反向代理；API Key 只存服务器配置文件，页面不回传明文。
    • 
        
  • 合规：系统内置敏感词检查，但发布前仍需人工过一遍；「地址托管」等平台禁限业务不得在内容里宣传，只可线下承接。
